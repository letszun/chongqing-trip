# 충칭·우롱 4박5일 여행앱

정적 웹앱(PWA)입니다. 별도 서버나 계정 없이 동작하며 체크 상태·예산·메모는 브라우저의 localStorage에 저장됩니다.

## 가장 간단한 사용법
1. `index.html`을 브라우저에서 열어 내용을 확인합니다.
2. PWA 설치/오프라인 기능까지 쓰려면 폴더를 웹서버에 올려 HTTPS로 접속합니다.
   - GitHub Pages / Netlify / Vercel 같은 정적 호스팅이면 충분합니다.
3. 모바일 브라우저에서 **홈 화면에 추가**를 선택하면 앱처럼 사용할 수 있습니다.

## 들어간 기능
- 8/25~8/29 전체 일정
- 충칭/우롱 장소 목록과 중국어명 복사
- 먹킷리스트 체크
- 2인 현지 예산 계산기
- 현지 중국어 문장 복사
- 출발 전 체크리스트
- 자유 메모 / 공동지출 메모
- 로컬 저장 및 기본 오프라인 캐시
